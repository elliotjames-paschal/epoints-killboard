What each table measures, where it comes from, and what it cannot see.

Timeline Glossary

The program

E-points (є-бали) is Ukraine's incentive program ("Армія дронів.Бонус", launched August 2024) in which military units earn points for video-verified output — strikes, and later reconnaissance, logistics, and other task families. Points are redeemable for equipment through the Brave1 Market procurement marketplace (launched April 2025). The killboard ("Підрахуйка", sbs-group.army) is the public scoreboard of the Unmanned Systems Forces (USF) publishing verified monthly output per unit.

What the killboard cannot see: the killboard covers USF drone units' verified strike and reconnaissance output only. Several priced categories — UGV logistics, capture of prisoners, sniper kills, army aviation, suicide videos — never appear on it. The on_killboard flag in categories.csv marks each category as yes, partial, or no; analysis joining prices to killboard output is only possible where it is yes.

panel.csv — the merged analysis panel

One row per unit × month × priced category: killboard output next to the price in force that month. Generated from the tables below on every update — treat those as the source of truth and this as the convenience join.

ColumnDefinition
outputVerified count for the category's primary basis that month (kills, destructions, captures, missions). Blank when on_killboard is no — unobservable, not zero. For partial categories it sums the related target classes (see categories.csv notes).
output_damagedHit-but-not-necessarily-destroyed count, where the killboard reports it.
points, points_max, points_basisPrice in force on the 1st of the month for the basis named in points_basis (a category with several live bases reports the highest-priority one: kill > destroyed > capture > mission > event > wounded; the full set is in prices.csv). Blank = not yet priced, or value never published.
points_damagedPrice in force for damage (per_hit), where one exists.
price_confidenceCarried from the matched prices.csv row. For bracket-dated repricings (the 2025 infantry doubling) the new price applies from the bracket's start.

prices.csv — price intervals

One row per (category, basis, validity interval). Every row has a source.

ColumnDefinition
category_idKey into categories.csv.
basisWhat earns the award: per_kill, per_wounded, per_destroyed, per_hit (damaged, not destroyed), per_capture, per_mission, per_event.
points, points_maxPoint value. Only points_max set means the source reported "up to N". Both set means a documented range.
valid_from, valid_toValidity interval. Empty valid_to = in force as of the last update. Dates carry only the precision in from_precision (day, month, snapshot, bracket).
confidencehigh = primary source (MOD, Fedorov, Brave1); med = reliable press, exact date unpinned; low = disputed between sources (see note).
sourceURL supporting this exact value and interval. Rows without a source do not ship — the build fails.

events.csv — the timeline

ColumnDefinition
date, precisionWhen it happened; precision is day, month, quarter, or bracket (bounded window) — dating of early repricings is genuinely contested, and the file says so rather than guessing.
typegenesis (pre-launch), launch, reprice (value change), expansion (new task family priced), platform (infrastructure), proposal (floated, not yet in force).
event, detailWhat changed, with values where documented.
confidence, sourceAs in prices.csv.

categories.csv — category registry

ColumnDefinition
category_idStable key used across tables.
task_familystrike, recon, logistics, capture, air_defense, mining, inducement.

killboard_monthly.csv — unit-month output

Collected weekly from the killboard's public API; one row per unit per month; the aggregate appears as unit USF Grouping.

ColumnDefinition
unit, monthUSF unit (English title as published) and calendar month.
collected_atTimestamp the killboard reported for this data snapshot. The current month's row is a running partial count until the month closes.
personnel_killed, personnel_woundedVerified enemy personnel casualties.
strike_missions, recon_missionsMission counts by type.
total_hit, total_destroyedVerified targets hit (incl. damaged) / destroyed, all classes.
tc01_hit … tc43_destroyedHit / destroyed counts per target class — key in target_classes.csv (Ukrainian original, English translation, analytic group, translation confidence).

killboard_reconstructed.csv

The killboard publishes monthly periods from October 2025 onward consistently; the 11 June – 30 September 2025 block in this file is reconstructed (per-unit method column documents how, e.g. yearly totals minus observed months) and spans a window, not calendar months. Treat it as one aggregate observation per unit, not four monthly ones.

Collection & caveats

A scheduled job pulls the killboard API weekly, revalidates every table (sources present, intervals consistent, no month gaps), and republishes — the repository's git history preserves every prior snapshot. The killboard is a self-reported official scoreboard of verified output; "verified" means video-verified through Ukraine's Delta/Brave1 pipeline, not independently audited. Point values are compiled from official announcements and reliable press; where sources disagree (the program's launch value for infantry, the dating of the first repricing), the dataset records the disagreement in confidence and note columns instead of resolving it silently.
